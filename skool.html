Tech Tip:

Programmers, and specifically app and web developers are usually catagorized into two types:

Front End Developers,

Back End Developers.

Front End Developers program all the visual effects and website design that you can see.

Back End Developers provide all of the functions under the hood of the website, and they organize the database that the code is run on.

Salary

The average salery of a programmer is around $100,000 per year.

At least, that's what's said on paper. But in reality, there is a vast difference between Front End Developers, Back End Developers, Video Game Developers, and so on. So, according to the recruiting company Indeed, the average salary for a Front End Dev is about $115,000 per year, a Back End Dev makes about $150,000, and a Video Game Dev makes a surprisingly low $87,000. All of these prices are taken in the US on average for each job, and salary still varies wildly based on employer, country, and experience.

Job Growth and Overall Health

The Demand for Computer Programmers seems to be dwindling, possibly because of AI. Some AIs like Microsoft Copilot can code lots of front end code quickly, however, AI is not always right, and websites made by AI are not as customizable as a Front End Developer. With more of the Drag and Drop website building website tools, front end website developing is looking less popular than before, but Back End Developers will likely still be in demand for some companies.
