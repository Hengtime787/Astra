Hi, _Matthew.heng.org_ is my personal/portfolio website. I use it to showcase my latest projects, happenings, and just to brag about myself sometimes. Updates on my current projects, _Atlas_ and _Antimatter_ will be posted there, as well as on their respective Github pages.

-------- Design Language -------

- Minimal UI, designed to let user use webpage without disruption or pop-ups
- Smooth Animations, without lag, to make site feel fluid
- Speed over everything, with all animations found to be efficient and quick, as well as efficient and sparing use of JS, which naturally has slow integration

-------- QOL Features --------

- Uses <alt> tags for accessibility
- Uses footer for external links, and disclaimer

-------- Styling --------

- Uses CSS Media Queries to make website adaptive to different devices
- Uses adaptive Nav Bar, for better cross platform experience
- Uses blur & transparency in an efficient way, making website appear more open and modern
- Uses animations that improve flow and make site more intuitive (such as helpful hover animations on nav links for desktop)

-------- How I used JavaScript --------

Javascript (JS) is only used where it absolutely needs to be, and no libraries are used, for better performance. JS generally detracts from website loading speed and efficiency, so it is used only in a few functions.

1 - To toggle the class of the nav bar module, to chagne from a set of navigation links into a neat navigation bar, for cross platform compatibility.

2 - To add a replaceable footer from a separate html file.

3 - To add replacable navigation module froma separate html file.

All functions are desigend to be low cost, in terms of performance and efficiency.
